1

환경과 카메라

카메라 테스트는 아래 UI 영상으로 표시됩니다. 텔레옵 중에는 GUI가, 녹화 중에는 저장 프로그램이 한 번씩만 카메라를 연결합니다. 집중 모드는 사용자가 버튼을 눌러 선택적으로 엽니다.

2

로봇 조작

추적 모드

시작 전 작업영역을 확인합니다. 텔레옵은 초기 자세 복귀 뒤 시작됩니다. 추적 모드는 텔레옵과 데이터 수집에 함께 적용됩니다. Endpoint 추적은 GELLO의 TCP 위치만 따라가고 관절 궤적은 xArm planning이 결정합니다.

3

데이터 수집

초

데이터 수집 준비 뒤 화면 버튼으로 녹화 시작·저장·폐기·종료를 선택합니다.

성공 시연 목록을 불러오는 중입니다.

!

오류 복구 (C1 · C31 · C19)

C1(비상정지): 버튼을 물리적으로 해제한 뒤 단계별로 승인합니다.

C31(충돌/과전류): 먼저 C31 복구 시작을 누르세요.

C19(그리퍼/끝단 통신): 케이블 점검 후 통신만 복구하며 팔·그리퍼는 움직이지 않습니다.
